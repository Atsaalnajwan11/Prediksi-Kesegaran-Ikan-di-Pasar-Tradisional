# Random Forest - Prediksi Kesegaran Ikan di Pasar Tradisional

Jalankan di komputer:
    pip install -r requirements.txt
    streamlit run app.py

Deploy ke streamlit.app (gratis):
1. Buat repository GitHub baru, unggah app.py dan requirements.txt.
2. Buka share.streamlit.io, login dengan GitHub, klik "Create app".
3. Pilih repository, branch main, file app.py, lalu Deploy.
